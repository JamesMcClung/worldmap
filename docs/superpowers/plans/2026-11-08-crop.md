# Crop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `make_map --crop NAME` / `--crop lon,lat:lon,lat` renders a zoomed map of one region in a projection centred on it.

**Architecture:** `MapFrame` grows a CRS, a `globe` flag, lon/lat clip boxes and a size in inches, and takes over
`data.project`, so every stage projects through the frame. A new `crop.py` builds a Lambert azimuthal
equal-area frame around a box or around the label(s) a name matches (prompting with `questionary` when several
match). Without `--crop`, the world frame is exactly today's, so existing fingerprints don't move.

**Tech Stack:** Python, geopandas/shapely/pyproj, matplotlib, `questionary` (new).

**Spec:** `docs/superpowers/specs/2026-11-08-crop-design.md`

## Global Constraints

- Without `--crop`, every fingerprint in `tests/fingerprints.json` still matches, except `regions` after Task 2.
- Commits follow `~/.claude/CLAUDE.md`: `X: desc` / `X; *: desc` / `+X`; never amend; trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. A commit that changes output re-records with `UPDATE_REFERENCE=1 .venv/bin/pytest` and says in its body what changed visually.
- `.venv/bin/mypy src` reports no issues; `test_import_has_no_pyplot` still passes (import `questionary` inside the function that prompts).
- Box order is `lon,lat:lon,lat`; corners in any order; the narrower longitude span wins.
- Named-crop margin: 10% of the region's projected size on each side. Box crop: no margin.
- The long side of a crop image is 36 in (`POSTER_WIDTH_IN`) at `DPI`.
- Projection: `+proj=laea +lat_0=<lat> +lon_0=<lon> +datum=WGS84`.

### Task 3: Crop geometry (`crop.py`)

**Files:**
- Create: `src/worldmap/crop.py`, `tests/test_crop.py`

**Interfaces:**
- Consumes: `MapFrame` fields from Task 1.
- Produces:
  - `CropBox = tuple[float, float, float, float]` (west lon, south lat, east lon, north lat); west > east means it crosses the antimeridian.
  - `parse_box(s: str) -> CropBox | None`: `None` if `s` isn't of the form `num,num:num,num` (then it's a name); `ValueError` for a lat outside +-90 or a lon outside +-180. Of the two longitude spans between the corners, take the narrower one.
  - `box_region(b: CropBox) -> BaseGeometry`: the box as lon/lat polygon(s), split at +-180 when it crosses.
  - `sphere_centre(geom: BaseGeometry) -> tuple[float, float]`: lon/lat of the normalised mean of the unit vectors of the geometry's vertices after `shapely.segmentize(geom, 0.5)`.
  - `crop_frame(region: BaseGeometry, margin: float) -> MapFrame`: LAEA at `sphere_centre(region)`; extent = bounds of the projected segmentized region, grown by `margin` times its width/height on each side; `globe=False`; `outline` = the canvas rectangle's 4 corners; `clip=clip_boxes(...)`.
  - `clip_boxes(to_lonlat, to_map, canvas: Polygon) -> tuple[LonLatBox, ...]`: algorithm below.
  - Constants `CROP_MARGIN = 0.10`, `CLIP_PAD_DEG = 5`.

`clip_boxes`: inverse-project a 65 x 65 grid of points over `canvas` grown by `PROJECT_PAD`; lat range = min/max of the sampled lats, padded by `CLIP_PAD_DEG` and clamped to +-90. If a pole projects inside the grown canvas, extend lat to that pole and use lon -180..180. Otherwise the lon range is the complement of the largest gap between the sorted sampled lons (circularly), padded by `CLIP_PAD_DEG`; if it wraps past +-180, return two boxes split there. Raise `ValueError("crop too large: ...")` if the antipode of the centre lies in a returned box (LAEA is singular there).

- Produces, in `crop.py`:
  - `@dataclass(frozen=True) class Candidate: text: str; kind: str; geom: BaseGeometry` (lon/lat). `kind` is one of `country`, `territory`, `disputed`, `ocean`, `sea`, `lake`, `strait`, `river`.
  - `candidates(label: set[str], disputed: bool) -> list[Candidate]`: built in the world frame (`make_frame()`), then converted to lon/lat (`to_crs("EPSG:4326")`). Countries: `is_labeled` rows' text after `RENAME`, geometry = their polygons minus those any `ChildRegion` of theirs takes. Territories: `ChildRegion.text`, its polygons. Disputed (with `disputed` and `countries`): the `relabel`/`extra` labels. Water/rivers: `load_water_bodies` for `kinds_from_labels(label)` (both Pacific halves stay separate candidates).
  - `fold(s: str) -> str`: NFKD, drop combining marks, casefold.
  - `matches(name: str, cands: list[Candidate]) -> list[Candidate]`: `fold(name) in fold(c.text)`; exact (`fold` equal) first, then the rest, each group sorted by kind order above then text.
  - `describe(c: Candidate) -> str`: `"Colorado (river) 109.5°W 36.2°N"`, the point being the representative point (a line's midpoint).
  - `choose(name: str, found: list[Candidate]) -> list[Candidate]`: none -> `sys.exit(f"--crop {name}: no label matches")`; one -> it; several and `sys.stdin.isatty()` -> `questionary.checkbox` of `describe` lines, at least one required, `None` (Ctrl-C) exits; several without a tty -> `sys.exit` with the `describe` lines.
  - `cli.make_map_frame`: a non-box `--crop` with `label == {"none"}` exits with an error; else `crop_frame(union of chosen geoms, CROP_MARGIN)`.
- With `--type topographic`, the kinds searched are `args.label` as given, so the default `countries` still finds countries.
